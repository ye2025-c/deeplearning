### 自动微积分

​	求导是深度学习*优化算法*的关键步骤。对于复杂的模型，深度学习通过自动计算导数，来快速求导。**实际中，根据设计 好的模型，系统会构建一个计算图（computationalgraph），来跟踪计算是哪些数据通过哪些操作组合起来 产生输出。自动微分使系统能够随后反向传播梯度。这里，反向传播（backpropagate）意味着跟踪整个计算 图，填充关于每个参数的偏导数。**



#### Example

​	对于$y=2X^TX$关于列向量$X$求导。首先创变量x并分配初始值。-在我们计算y关于x的梯度之前，需要一个地方来存储梯度。重要的是，我们不会在每次对一个参数求导时都 分配新的内存。因为我们经常会成千上万次地更新相同的参数，每次都分配新的内存可能很快就会将内存耗 尽。注意，一个标量函数关于向量x的梯度是向量，并且与x具有相同的形状。

`````python
import torch
x=torch.arange(4.0)
#>>>tensor([0.,1.,2.,3.])
x.requires_grad_(True)
#=>x=torch.arange(4.0,requires_grad_=True)
x.grad #default is None
y=2*torch.dot(x,x)
#>>>tensor(28.,grad_fn=<MulBackward0>)
#x与x的点乘赋值给y为标量输出。接下来通过反向传播函数自动计算梯度。
y.backward()#反向传播函数
x.grad
#tensor([0.,4.,8.,12.])
#函数的梯度为4x,可以快速验证
x.grad==4*x
#>>>tensor([True,True,True,True])
#在默认情况下，PyTorch会累积梯度，我们需要清除之前的值
x.grad_zero_()
y=x.sum()
y.backward()
x.grad
#teensor([1.,1.,1.,1.])

`````

#### 非标量变量的反向传播

$$
\int\int_{D} f(x,y)d\sigma=\int_{a}^{b}dx\int_{g(x)}^{q(x)}f(x,y)dy
$$

​	*当y不是标量时，向量y关于向量x的导数的最自然解释是一个矩阵。对于高阶和高维的y和x，求导的结果可以 是一个高阶张量。*

```python
#对应于非标量调用backward,需要传入gradient参数，指定微分函数关于slef的梯度，
#只想求偏导数的和，传递1就行
x.grad.zero_()
y=x*x
#=>y.bacward(torch.ones(len(x)))
y.sum().backward()
x.grad
#>>>tensor([0.,2.,4.,6.])
```

#### 分离计算

，假设y是作为x的函数计算的，而z则是作为y和x的 函数计算的。想象一下，我们想计算z关于x的梯度，但由于某种原因，希望将y视为一个常数，并且只考虑 到x在y被计算后发挥的作用。

```python
x.grad.zero_()
y=x*x
u=y.detach()
z=u*x
z.sum().bacward()
x.grad == u
#>>>tensor([True*4])
x.grad.zero_()
y.sum().backward()
x.grad == 2*x
#同上
```

​	==总结==：

​		多元函数的求导，单个参数偏导，其他视为常数。这是数学过程。在python中，用 **y.detach()**来分离计算。



#### python控制流的梯度计算

```python
def f(a):
    b=a*2
    while b.norm()<1000:#b.norm()为L2范数
        b=b*2
    if b.sum()>0:
        c=b
    else:
        c=100*b
    return c
```

计算梯度：

```python
a=torch.rand(size(),requires_grad=True)
d=f(a)
d.backward()
a.grad == d/a
#tensor(True)
```

​	**分析**：这是一个$f(a)=ka$线性函数，k为某个常量标量，k依赖输入的a.所以可以用d/a验证梯度的正确与否。
