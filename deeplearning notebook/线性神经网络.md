## 线性回归

​	给定一个数据集，我们的目标是寻找模型的权重w和偏置b，使得根据模型做出的预测大体符合数据里的真实 价格。输出的预测值由输入特征通过线性模型的仿射变换决定，仿射变换由所选权重和偏置确定。

比如：
$$
price=w_{area}*area+w_{age}*age+b
$$




$y_{pre}=\Sigma_{i=1}^{d}w_ix_i + b$

or

$y_{pred}=W^TX+b$

or

**$y_{pred}=XW+b$**



​	*给定训练数据特征X和对应的已知 标签y，线性回归的目标是找到一组权重向量w和偏置b：当给定从X的同分布中取样的新样本特征时，这组权 重向量和偏置能够使得新样本预测标签的误差尽可能小。*

​	在开始寻找最好的模型参数（modelparameters）w和b之前，我们还需要两个东西：（1）一种模型质量的度 量方式；（2）一种能够更新模型以提高模型预测质量的方法。

### 损失函数

损失函数（lossfunction） 能够量化目标的实际值与预测值之间的差距。通常我们会选择非负数作为损失，且数值越小表示损失越小， 完美预测时的损失为0。

回归问题中最常用的损失函数是平方误差函数。当样本i的预测值为$y_{pred}(i)$，其相应的真 实标签为y(i)时，平方误差可以定义为以下公式：
$$
l^{i}(w,b)=(y_{pred}(i)-y(i))^2/2
$$
由于平方误差函数中的二次方项，估计值ˆy(i)和观测值y(i)之间较大的差异将导致更大的损失。为了度量模型 在整个数据集上的质量，我们需计算在训练集n个样本上的损失均值（也等价于求和）。
$$
L(w,b)=\frac{\Sigma_{i=1}^{n}l^{(i)}(w,b)}{n}=\frac{1}{n}\Sigma_{i=1}^{n}\frac{1}{2}(W^TX^{(i)}+b-y^{(i)})^2
$$
在模型训练时，我们希望找到一组参数$(w^*,b^*)$,这组参数能最小化所有训练样本的总损失：
$$
w^*,b^*=argmin_{(w,b)}L(w,b)
$$

#### 解析解

​	线性回归是一个简单优化问题。能给出公式表达，这类解叫做*解析解（analytical solution）*。

将损失关于w的导数设为0：
$$
w^* = (X^TX)^{-1}X^Ty
$$

但解析解有局限：要求 $X^TX$ 可逆，且矩阵求逆计算量为 $O(n^3)$，特征维度高时不可用。

#### 梯度下降

​	实际训练中用**梯度下降（gradient descent）**迭代更新参数。对 MSE 损失，梯度为：
$$
\frac{\partial L}{\partial w} = \frac{1}{n} X^T(Xw - y)
$$

参数更新规则（学习率 $\eta$）：
$$
w \leftarrow w - \eta \frac{\partial L}{\partial w}
$$

#### 小批量随机梯度下降（mini-batch SGD）

​	每次不用全量数据，随机抽 $B$ 个样本估计梯度，兼顾计算效率与收敛速度：
$$
w \leftarrow w - \frac{\eta}{B} \sum_{i \in \mathcal{B}} \frac{\partial l^{(i)}}{\partial w}
$$

两个关键超参数：**学习率** $\eta$（步长）、**批量大小** $B$（每次用多少样本）。

## Softmax 回归

### 从回归到分类

​	线性回归输出的是连续值（如房价）；分类问题输出的是**离散类别**（如猫/狗/鸟）。

​	对于 $q$ 个类别，我们用 $q$ 个输出节点，每个节点对应一个类别的"得分"（logit）：
$$
o_j = w_j^T x + b_j, \quad j = 1, \ldots, q
$$

​	这些得分需要转成**概率**：满足非负且和为 1。这就是 softmax 的作用。

### Softmax 算子

$$
\hat{y}_j = \text{softmax}(o)_j = \frac{\exp(o_j)}{\sum_{k=1}^{q} \exp(o_k)}
$$

特性：
- $\hat{y}_j \in (0, 1)$，所有类别概率之和为 1
- 保持各 $o_j$ 的相对大小（指数放大差距）
- 矩阵形式：$\hat{Y} = \text{softmax}(XW + b)$

### 数值稳定性

​	直接计算 $\exp(o_j)$ 在 $o_j$ 很大时溢出。实践中先减去最大值（不改变结果）：
$$
\hat{y}_j = \frac{\exp(o_j - \max_k o_k)}{\sum_{k} \exp(o_k - \max_k o_k)}
$$

```python
def softmax(X):
    X_exp = torch.exp(X - X.max(dim=1, keepdim=True).values)  # 数值稳定
    return X_exp / X_exp.sum(dim=1, keepdim=True)
```

### 交叉熵损失

​	softmax 回归不用 MSE，用**交叉熵（cross-entropy）**衡量预测概率分布与真实标签的差距。

​	设真实类别为 $y$，预测概率为 $\hat{y}$，单样本损失：
$$
l(y, \hat{y}) = -\log \hat{y}_y = -\log \frac{\exp(o_y)}{\sum_k \exp(o_k)}
$$

​	展开后等于：
$$
l(y, \hat{y}) = \log \sum_k \exp(o_k) - o_y
$$

**为什么用交叉熵而不用 MSE？**
> MSE 对概率输出不敏感，梯度会饱和；交叉熵的梯度 $\hat{y}_j - \mathbb{1}[j=y]$ 简洁且不饱和。

### 代码实现（从零）

```python
# 交叉熵：取真实类别对应的预测概率，取负对数
def cross_entropy(y_hat, y):
    return -torch.log(y_hat[range(len(y_hat)), y])

# 准确率
def accuracy(y_hat, y):
    preds = y_hat.argmax(dim=1)
    return (preds == y).float().mean().item()
```

### 与线性回归的对比

| 维度 | 线性回归 | Softmax 回归 |
|------|----------|--------------|
| 任务类型 | 回归（连续值） | 分类（离散类别） |
| 输出层激活 | 无（恒等映射） | Softmax |
| 损失函数 | 均方误差（MSE） | 交叉熵 |
| 输出解释 | 预测数值 | 各类别概率 |
| 都是线性模型 | ✓ | ✓（决策边界是线性的） |

### 训练流程（以 Fashion-MNIST 为例）

```
输入 28×28 图像 → 展平为 784 维向量
→ 线性层 (784 → 10)
→ Softmax → 10 类概率
→ 交叉熵损失 → 反向传播 → SGD 更新
```
