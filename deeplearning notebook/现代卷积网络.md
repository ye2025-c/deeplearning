## 5. 批量规范化（Batch Normalization）

**Q：BN 在解决什么问题？训练和推理时的行为差异？**

关键公式：
$$
\hat{x} = \frac{x - \hat{\mu}_\mathcal{B}}{\sqrt{\hat{\sigma}_\mathcal{B}^2 + \epsilon}}, \qquad
y = \gamma \hat{x} + \beta
$$

要点清单：
- [ ] 训练用小批量均值/方差；推理用移动平均
- [ ] 放在卷积/全连接之后、激活之前
- [ ] 可学习参数 $\gamma, \beta$

## 架构对比速查

| 网络 | 年份 | 关键创新 |
|------|------|----------|
| LeNet | 1998 | 第一个 CNN |
| AlexNet | 2012 | 深度 + ReLU + Dropout |
| VGG | 2014 | 重复小卷积块 |
| NiN | 2013 | 1×1 卷积 + 全局平均池化 |
| GoogLeNet | 2014 | Inception 并行多尺度 |
| ResNet | 2015 | 残差连接 |
| DenseNet | 2017 | 稠密拼接 |
