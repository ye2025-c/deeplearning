**任务：搞清楚手动版和简洁版每个模块的对应关系**

打开 `线性回归实例.py` 和 `线性回归简洁实现.py`，逐模块对照，回答下面每个问题（用自己的话，写在纸上或注释里）：

| 手动版 | 简洁版 | 要回答的问题 |
|--------|--------|------------|
| `synthetic_data` | `d2l.synthetic_data` | y 为什么要加 `torch.normal` 噪声？ |
| `data_iter` (yield) | `DataLoader` | `shuffle=True` 去掉会怎样？ |

## 遇到卡住怎么办

| 卡住类型 | 处理方式 |
|---------|---------|
| API 名字/参数记不住 | 允许查 PyTorch 文档，不允许看自己的代码 |
| 逻辑想不通 | 先动手跑，打印中间变量的 shape 来推断 |
| 卡住超过15分钟 | 看一眼参考代码，合上后重新写，不要边看边抄 |
| 运行报错 | 先自己读报错信息，定位是 shape 问题还是 API 用法问题 |
